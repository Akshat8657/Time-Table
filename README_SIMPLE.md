# TimeTablePro - Simple Guide

1. **START:** `Start TimeTablePro` par double-click karo - koi window nahi dikhegi, browser me TimeTablePro khud khul jayega.
2. **LOGIN:** Browser me `http://localhost:5173` par apna email + password daalo (pehli baar naya password set karna padega).
3. **STOP:** `Stop TimeTablePro` par double-click karo (dono servers peeche se band ho jayenge).
