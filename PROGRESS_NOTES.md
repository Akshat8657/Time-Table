- **One idea = DayChanges overlay** (`services/changes.py`): `load_changes(school, term, window)` reads the date's absences + substitutions + one-day adjustments into a small indexed object (`is_absent`, `subs_at`, `adjustment_for`, `covering`), which `views.build_cells(..., change=)` paints onto the published cells. `change=None` -> byte-for-byte the old Phase 4 output (so Phase 4 views/tests are untouched). `stats_of` kept its original 4 keys; new day counts live in a separate `day_extra_stats`.
- **Absence** (`routers/absence.py`): `POST /api/absence` - a teacher marks THEMSELVES (today or a date, optional reason); a HOD marks anyone in their school, an admin anyone. Marking it, in ONE transaction: inserts `teacher_absences` (unique `teacher_id+absence_date`, 409 if already), creates an OPEN `substitutions` row for every lecture that day that no PRESENT co-teacher already covers (a combined session = ONE need across its classes; a holiday/one-day-cancel slot is skipped), audits, and notifies the HOD/Admin (+ the teacher if someone else marked them). A HOD's OWN absence goes to the admins (`subflow.managers_of(exclude=self)`). `GET /api/absence` (managers, by date), `/mine` (teacher), `/{id}/affected`, `DELETE /{id}` (future only; frees its subs, tells anyone already assigned/offered).
- **Leave** (`routers/leave.py`): `POST /api/leave` (teacher or HOD) a date or range + reason -> `leave_requests` (status pending) -> HOD notified (a HOD's own request -> admins). `POST /{id}/decide` approve/reject: approve writes a `teacher_absences` row (source `leave`) for every WORKING day in the range and runs the same make-subs flow, reject just notifies; the requester is told either way. `GET /api/leave?scope=mine|school`, `POST /{id}/cancel`.
- **Ranking** (`services/substitution.py`, pure logic): `free_at` = active + not absent + (visiting faculty only on their visiting days) + not already busy (base week + that day's moves/extras/accepted subs). `rank_candidates` returns ONLY free teachers, scored by the plan's four things with human reasons: (a) can teach the subject (+100) / specialization keyword match (+45) / else "available to supervise" (+8); (d) has taught this class before (+25); (c) lower load that day (+24 - 6*load, "Free all day"); visiting faculty -6. Each carries `reasons[]` so the HOD sees WHY. `load_qualification` reads who-can-teach-what + who-taught-this-class-before + specialization text.
- **Substitution console + two modes** (`routers/subs.py`): `GET /api/subs?date=` (managers, the day's needs + a status summary), `GET /{id}/candidates` (the ranking). **Manual**: `POST /{id}/assign {teacher_id}` - re-checks free, fills, supersedes any pending offers, notifies the substitute + absent teacher + HOD. **Auto offer (the USP)**: `POST /{id}/offer {count=5, timeout_minutes?}` - inserts a `substitution_offers` row (status pending) per top-N free teacher and sets the sub `offering` with an `offer_deadline = min(now+timeout, lecture start IST)`; each offered teacher gets an in-app popup + push. `POST /{id}/accept` is **first-accept-wins**, made safe with `SELECT ... FOR UPDATE` on the sub row + a status re-check inside the tx: the first accept fills it and supersedes the rest; a later accept gets **409 ALREADY_FILLED** ("already filled"); re-checks free at accept time too. `POST /{id}/decline`, `POST /{id}/cancel`. `GET /api/subs/my-offers` (a teacher's open offers + what they are covering). Default timeout = `settings.substitution_offer_minutes` (10).
- **Timeout sweep** (`subflow.sweep`, run every 60 s by a `main.py` lifespan task): rounds whose `offer_deadline` passed (or whose lecture already started) are closed - pending offers -> `expired`, the sub -> `unfilled`, and the HOD is alerted to assign manually. Safe to run from anywhere (locks each row, idempotent).

Each response gained a `day_stats` block (covering / my_absent / needs_sub / cancelled_today / moved). `GET /api/subs/sheet?date=` = the day's printable **Daily Substitution Sheet** PDF (reportlab, `exporter.substitution_sheet_pdf`); `GET /api/subs/summary?month=` = the monthly per-teacher summary (absences / covered / needed) + totals.
- **One-day adjustments** (`routers/adjust.py`, `services/adjust.py`): `GET /api/adjust?semester_id=&date=` lists that date's lectures + which are adjustable (combined sessions are not). `POST /move` / `/cancel` / `/swap` write `day_adjustments` (kind move|cancel; a swap = two move rows sharing a `swap_group`) with LIVE clash checks (`can_move`: class free + every teacher free at the new slot, inside the class's day window, no holiday) - the weekly timetable never changes. A cancel also cancels any substitution at that slot and counts as a **lost hour** (`hours.compute_hours` gained a `cancelled` set; `routers/hours.py` feeds it the day-cancels). Affected teachers are notified. `DELETE /{id}` undoes it (a swap undoes both halves). **Smart suggestions** `GET /api/adjust/suggest`: clash-free periods to move the lecture to, and same-length lectures of the class it could swap with, with reasons - one click applies.

Randomized greedy construction (most-constrained first) + depth-1 ejection + hill-climb sweeps; 12 seeded attempts; keeps the top 2-3 DISTINCT solutions (signature difference >= 12%). Real dataset (8 classes, 160 placement instances): ~3 s to solve, ~30 s for a whole run incl. saving. Deterministic per seed.
